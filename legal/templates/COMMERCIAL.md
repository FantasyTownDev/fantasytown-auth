# FantasyTown-Auth · 商业授权（独立合同）

> **这不是许可证条款，也不改变 AGPLv3 的任何授权范围。**
> AGPLv3 允许商用、允许收费、允许 SaaS，只要遵守其源码开放义务（§5/§13）。
> 本文件是**本项目版权人另行提供的一种付费服务/授权选项**，供有需要的一方自愿选择。
> **不接受本商业授权，不影响你依 AGPLv3 本可享有的任何权利。**

---

## 1. 为什么会有这一份

有些使用者希望获得 AGPLv3 之外的便利，例如：

- 不公开其改动源码的商业闭源部署；
- 使用本项目名称/标识做产品或品牌（见 TRADEMARK.md）；
- 获得 SLA、技术支持、安全响应、定制开发、责任限制等。

这些**不是 AGPLv3 给你的**，所以通过**双方另行签订的书面商业许可协议**提供。

## 2. 本文件的性质

- 这是一份**要约邀请（非强制前置许可）**：你发需求，我方回复，双方签署书面协议后生效；
- **不存在“未邮件申请即侵权”**这种逻辑。是否侵权只按 AGPLv3 + NOTICE.md §7 + 商标规则判断；
- 商业协议签署后，对签署方在其约定范围内**取代** AGPLv3 的相关义务（协议会写明）；
- 协议未覆盖的部分，AGPLv3 继续适用。

## 3. 洽谈时请准备的信息

| 项目 | 说明 |
|---|---|
| 主体 | 个人或公司名称、统一社会信用代码/注册信息 |
| 用途 | 自用托管 / 对外 SaaS / 发行镜像 / 嵌入产品 |
| 是否改动代码 | 改动范围、是否愿意开源 |
| 品牌使用 | 是否需要用 FantasyTown 名称或标识 |
| 服务需求 | SLA、响应时限、定制、培训 |
| 期限与地域 | 合同期、部署区域 |
| 费用口径 | 按席位 / 按实例 / 一次性授权（双方约定） |
